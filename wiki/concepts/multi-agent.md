# 單一 Agent 與多 Agent

> 任務變複雜時，Agent 怎麼分工。

<!-- 每個主張固定格式：### ID／陳述／來源／引文。tools/lint_wiki.py 會檢查引文是否真的出現在 raw/ 的原文裡。 -->

### MULTI-1
陳述：單一 Agent 系統：一個配備工具與指令的模型，在迴圈中執行工作流程。
來源：S3
引文：「Single-agent systems, where a single model equipped with appropriate tools and instructions executes workflows in a loop」

### MULTI-2
陳述：管理者模式：一個中央「管理者」Agent 透過工具呼叫，協調多個各自負責特定任務的專門 Agent。
來源：S3
引文：「A central “manager” agent coordinates multiple specialized agents via tool calls, each handling a specific task or domain.」

### MULTI-3
陳述：交接（handoff）是單向轉移，讓一個 Agent 把工作委派給另一個 Agent。
來源：S3
引文：「Handoffs are a one way transfer that allow an agent to delegate to another agent.」

### MULTI-4
陳述：多 Agent 系統由多個 Agent 合作或競爭，來達成共同目標或各自的目標。
來源：S6
引文：「Multiple AI agents that collaborate or compete to achieve a common objective or individual goals.」
